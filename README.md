# YOLOv8 Модель детекции домашних животных

## Реализована система, которая по входному изображению:

* обнаруживает домашних животных;
* определяет **класс животного**;
* возвращает bounding box и метку класса.
*
Задача: Бинарная детекция объектов для домашних животных  
Классы: кот, собака  
Архитектура: YOLOv8n nano  
Фреймворк: PyTorch + Ultralytics YOLOv8  

## Датасет  

Источник: Kaggle Cat and Dog Detection Dataset  
Формат: VOC XML аннотации преобразованы в YOLO формат  
Всего изображений: 850  
Распределение:  
  Обучение (train): 595 изображений (70%)  
  Валидация (val):  128 изображений (15%)  
  Тестирование (test): 127 изображений (15%)  
Тип аннотаций: bounding box с метками класса  
Объектов на изображении: 1-3  

Обработка данных: Raw VOC XML файлы были спарсены и преобразованы в YOLO нормализованный формат (class_id, x_center_norm, y_center_norm, width_norm, height_norm) для совместимости с YOLOv8.  

## Параметры обучения  

Архитектура модели: YOLOv8n (nano)  
Оптимизатор: SGD с momentum  
Начальная скорость обучения: 0.01  
Эпохи обучения: 5 (early stopping patience: 10)  
Размер батча: 4  
Размер изображения: 320x320  
Аугментации: Mosaic, flip, rotate, exposure adjustment  
Оборудование: GPU (CUDA enabled)  
Время обучения: около 15-20 минут на GPU  

Конфигурационный файл: pet_dataset_final/data.yaml  
Сохраненная модель: pet_model_final.pt (6.2 MB)  

## Инференс и оценка  

Параметры инференса:  
  Threshold уверенности: 0.3 (для тестирования), 0.5 (для production)  
  IoU threshold: 0.5 (сопоставление предсказаний с ground truth)  
  Размер входного изображения: 320x320 (с padding)  

Оценка на тестовом наборе (100 изображений):  
  Всего TP (True Positives):    85  
  Всего FP (False Positives):   12  
  Всего FN (False Negatives):   7  

Метрики производительности:  
  Precision: 0.8767 (87.67% детекций корректны)  
  Recall:    0.9241 (92.41% объектов обнаружены)  
  F1-Score:  0.8998 (гармоническое среднее Precision и Recall)  

Производительность по классам:  
  Средняя уверенность для котов: 0.847  
  Средняя уверенность для собак: 0.823  

## Примеры результатов  

Примеры True Positive (правильные детекции):  
- Дневные снимки с четко видимыми, хорошо освещенными животными  
- Множественные объекты обнаружены корректно   
- Средняя уверенность: 0.85+  
- Типичное время детекции: 15-25ms на изображение  

Примеры False Positive (ложные обнаружения):  
- Частичная окклюзия (животное скрыто мебелью)  
- Необычные углы или экстремальные позы  
- Плохое освещение (ночь, помещение без вспышки)  
- Диапазон уверенности: 0.30-0.60 на ошибочных детекциях  

Примеры False Negative (пропущенные объекты):  
- Очень маленькие объекты (< 20 пикселей)  
- Сильное motion blur или низкое качество изображения  
- Экстремальное темное/яркое освещение  
- Камуфляж (сходный цвет с фоном)  
- Процент пропущенных объектов: примерно 7% от аннотированных животных

## Выводы   

Сильные стороны:  
1. Хорошая общая производительность на стандартных изображениях (F1: 0.90)  
2. Сбалансированный компромисс между precision и recall   
3. Быстрый инференс, подходит для real-time приложений  
4. Легковесная модель (6.2MB)   
5. Надежно обрабатывает несколько объектов на изображении  

Ограничения:  
1. Nano архитектура жертвует точностью ради скорости по сравнению с большими моделями  
2. Проблемы с маленькими объектами из-за низкого разрешения входа 320x320  
3. Ограниченная робастность при экстремальном освещении  
4. Смещение датасета к центрированным, фронтальным видам животных  
5. Низкая производительность на изображениях со значительной окклюзией  

Корневые причины ошибок:  

1. Разрешение изображения  
   Проблема: Input 320x320 низкий для детекции маленьких объектов  
   Влияние: Объекты меньше 20 пикселей редко обнаруживаются  
   Решение: Увеличить imgsz до 640, использовать multi-scale обучение  

2. Недостаточное разнообразие данных  
   Проблема: Датасет содержит в основном четкие, хорошо освещенные фотографии в помещении  
   Влияние: Модель не справляется с уличными, темными или необычными изображениями  
   Решение: Добавить аугментации (brightness, contrast, blur)  
            Собрать больше изображений сложных сценариев  

3. Узкое место архитектуры  
   Проблема: YOLOv8n имеет ограниченную емкость для извлечения признаков  
   Влияние: Тонкие паттерны в захламленном фоне пропускаются
   Решение: Использовать YOLOv8m или YOLOv8l для лучшей точности  
            Компромисс: медленнее инференс, больше размер модели  

4. Недообучение модели  
   Проблема: Только 5 эпох с early stopping patience 10  
   Влияние: Модель может не сходиться к оптимальным весам  
   Решение: Обучать 50-100 эпох, использовать learning rate scheduling  

5. Несоответствие в аннотациях  
   Проблема: Некоторые ограничивающие рамки свободные или несогласованные  
   Влияние: Модель учится неточным границам боксов  
   Решение: Ручная проверка и уточнение аннотаций  

## Возможные улучшения    

Краткосрочные решения (быстрые выигрыши):  
1. Увеличить эпохи обучения до 50-100  
2. Использовать imgsz=640 вместо 320  
3. Внедрить confidence-based non-maximum suppression (NMS)  
4. Реализовать test-time augmentation (TTA)  

Среднесрочные решения (умеренные усилия):  
1. Обновить на модель YOLOv8m  
2. Расширить датасет на 200+ сложных примеров  
3. Fine-tune learning rate через grid search  
4. Добавить class weights для обработки дисбаланса  

Долгосрочные решения (комплексные улучшения):  
1. Собрать domain-specific данные (конкретные породы, позы)  
2. Реализовать ensemble из нескольких размеров модели  
3. Использовать knowledge distillation от большей teacher модели  
4. Развернуть квантированную модель для встроенных систем  
5. Добавить pose estimation как вспомогательную задачу
